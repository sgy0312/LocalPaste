# Paste 交互参考与 LocalPaste 实现要求

参考于 2026-10-08。依据 [Paste 官网](https://pasteapp.io/) 与官方 Mac 帮助整理；以下是适合本地版的设计要求，不是要求照搬全部功能。

## 学习结果

| 官方交互 | LocalPaste 的实现要求 |
| --- | --- |
| 屏幕底部横向时间线、最新内容在前、显示内容预览/来源/时间 | 保留底部卡片栏；默认 1200 × 288，最小 640 × 272；让来源应用在卡片上可读，内容仍是主要视觉焦点 |
| 缩小高度时使用紧凑视图 | 保留现有随尺寸变化的布局；小尺寸下预览、固定、复制都可见，不额外增加默认高度 |
| 打字即可搜索，结果即时更新 | 保留原生搜索和中文输入法；关键词非空时搜索全部历史和固定内容，清除后回到此前的分组 |
| 搜索框中的筛选状态始终可见 | 为当前类型筛选显示中文名称和明确的清除操作；窄窗口仍可发现、解除筛选 |
| 搜索与结果之间可用 Tab 切换；搜索框回车先进入结果 | 输入关键词后第一次回车只移动焦点，保留关键词；结果区域回车再复制。上下方向键仍可进入结果，搜索中的左右键和空格保持原生编辑行为 |
| 键盘切换固定分组 | 在卡片区域支持 ⌘←/⌘→ 切换历史及固定分组；搜索编辑器中保持原生光标操作 |
| 空格完整预览、Esc 逐层返回 | 保留完整本地内容预览；Esc 先关闭预览、再清除搜索、最后关闭面板 |

依据：[Mac 界面与基本操作](https://pasteapp.io/help/paste-on-mac)、[搜索与筛选](https://pasteapp.io/help/search-and-filters)、[键盘快捷键](https://pasteapp.io/help/keyboard-shortcuts)、[固定分组](https://pasteapp.io/help/organize-with-pinboards)。

## 当前修正必须保留

- 默认高度从旧版 352 pt 迁移到 288 pt；自定义高度继续保留，窗口可拖动调整尺寸。
- 原生材质使用可拉伸的透明圆角遮罩，裁切子视图，解决圆角外露白底。
- 进入 240 ms、退出 160 ms；快速反向切换从当前位置与透明度继续，拖动时停止过渡，尊重系统减少动态效果。
- ⌘⇧V 呼出；所有历史只保存在本机，保留 1/3/5/7 天，默认 1 天；固定内容不自动清理。
- 复制后回到原应用，由用户按 ⌘V 粘贴。直接粘贴需要额外辅助功能权限，本次保持已有复制流程。

## ui-ux-pro-max 约束

使用系统字体、SF Symbols、原生控件及语义颜色。焦点清楚可见，空结果提供下一步操作，拖动有菜单替代操作，交互状态变化不改变控件尺寸。进入减速、退出加速，尊重减少动态效果。AppKit 桌面界面不套用手机触摸尺寸或新增 Web 框架。

## 本轮验收

1. 搜索框第一次回车不会意外复制；Tab 可在结果和搜索间切换，空格/左右键不破坏搜索文字编辑。
2. 在固定分组内输入关键词，也能找回其他分组及普通历史中的匹配内容；清除关键词恢复原分组。
3. 筛选状态可见且可清除；清除只移除类型筛选，保留关键词与分组。
4. 分组键盘切换不会在搜索编辑时抢占 ⌘←/⌘→，切换后所选分组可被发现。
5. 卡片来源名称可读，完整内容可预览；浅色/深色和最小/默认尺寸没有裁切或重叠。
6. 原有尺寸、动画、透明遮罩、记录保留及数据安全检查继续通过。

同步、账户、付费、协作、在线 AI、MCP、OCR、多选与自动直接粘贴不属于本次实现范围。
