# LocalPaste UI 与交互

这是一个仅保存在本机的原生 macOS 剪贴板工具。设计依据 ui-ux-pro-max 的简洁桌面风格、可见焦点、拖动替代操作和内容可读性指导，并结合 CodeArts 的界面方案落地。

## 界面层级

1. 顶部：常驻搜索、全部剪贴板、固定分组、新建分组、类型筛选、设置。
2. 中部：横向滚动的统一高度卡片，按最近复制时间排列。先显示内容类型与时间，再显示正文或缩略图，最后显示来源与元数据。固定内容用非按钮图标和辅助功能标签标示。
3. 底部：结果数量、可清除的类型筛选，以及必要的动态状态。正常浏览隐藏提示，错误通知优先显示，其次为暂停、搜索范围；隐私和期限见齿轮设置菜单，快捷键见“使用帮助”。

卡片无常驻操作按钮，释放的空间用于正文与缩略图。点击卡片复制该记录并返回刚才的应用，之后按 `⌘V` 粘贴。空格预览完整内容；右键菜单提供复制、预览、固定到指定分组、取消固定和删除。辅助功能通过卡片按压操作复制，通过自定义操作预览与固定。

## 视觉规范

| 项目 | 当前实现 |
| --- | --- |
| 字体 | macOS 系统字体；卡片正文 13 pt，链接标题 14 pt，预览正文 14 pt，辅助信息 11 pt |
| 面板 | 默认高 240 pt、原生毛玻璃材质，使用 behindWindow 采样桌面与后方窗口、细亮边、圆角 28 pt；可拉伸 alpha 遮罩裁切材质，图层圆角裁切子视图，屏幕底部居中 |
| 卡片 | 统一 184 × 128 pt、连续圆角 16 pt、间距 11 pt、内边距 12 pt；高度不随内容或面板拉高而增加，仅在很小屏幕中整体夹紧以保持可见；半透明磨砂填充、细边和柔影 |
| 文本 | 正文使用系统语义颜色；辅助文字使用随明暗主题切换的不透明颜色 |
| 选中状态 | 蓝色 2 pt 边框，并通过辅助功能值标示选中状态 |
| 图标 | SF Symbols；图标按钮有操作名称与工具提示 |
| 过渡 | 卡片颜色与阴影 160 ms；面板进入 240 ms、退出 160 ms；系统减少动态效果时关闭过渡 |

维持原生 AppKit 控件和文字编辑行为，无网络字体、在线图片或新增 UI 框架。这里的桌面尺寸与字号不照搬手机触控标准。

材质颜色集中在 `ShelfGlass`。每个窗口使用一层原生模糊，卡片叠加半透明背景，不为每张卡片单独采样桌面。开启系统“减少透明度”时，面板、卡片与预览阅读区改用实心底色；“增强对比度”会加深边界。通过 NSWorkspace 的通知中心监听显示选项变更，刷新现有视图，保留面板尺寸和选择状态。关闭视图时移除观察者。

内容预览与面板使用相同材质；文字阅读区增加底色，图片保持原色和比例。离线示例使用程序生成的蓝紫、暖橙渐变模拟透过玻璃的颜色，只在示例模式绘制。实际应用的颜色与模糊来自系统采样，会随后方桌面和窗口变化。

链接卡片离线识别 http/https、www 和整条裸域名，已知服务显示名称（如腾讯文档），未知域名显示主机；完整链接和原文可通过预览核对。仅明确 http/https/www 链接可从混合文字中识别；邮箱、版本号和普通代码标识符不归为网页。裸域名依赖系统离线识别，不验证网页是否存在，也不抓取标题或图标。识别结果在内存缓存，保留原始内容与本机持久化格式；复制始终使用完整原文。

## 键盘与焦点

| 场景 | 操作 |
| --- | --- |
| 全局 | `⌘⇧V` 呼出或关闭面板 |
| 卡片区域 | 左右方向键选择，回车复制，空格打开或关闭所选内容的预览；`⌘←` / `⌘→` 循环切换历史与固定分组 |
| 搜索 | `⌘F` 或单击搜索框；直接输入也会进入搜索；关键词非空时搜索全部历史与固定内容 |
| 编辑搜索 | 左右键和 `⌘←` / `⌘→` 保持原生光标操作，空格正常输入；回车或 Tab 先进入结果，再回车复制；上下键同样保留关键词并进入结果 |
| 返回搜索 | 结果区 Tab 或 Shift-Tab 返回搜索；原生按钮保留自己的焦点操作 |
| 类型筛选 | 底部显示“图片 ×”等清除按钮，只解除类型筛选，保留关键词与分组 |
| 退出 | Esc 先关闭预览，再清除搜索，最后关闭面板 |
| 预览 | 文字可以选中，窗口可以缩放；关闭按钮或 Esc 返回面板，复制按钮复制后返回原应用 |

图标按钮使用原生焦点环，卡片选择使用蓝色边框。这两种状态分别表示控件键盘焦点与当前选择，不宣称已完成所有辅助功能标准的认证。

全局搜索时分组标签不高亮，底部以“搜索全部内容”说明搜索范围；错误或暂停状态优先显示。清除关键词后恢复此前分组。点击分组标签、分组菜单或使用分组快捷键会结束搜索并进入该分组，类型筛选仍保留。快捷键选择的标签自动滚入可见区域。来源应用名称显示在卡片元数据中，截断的信息可以通过工具提示与卡片辅助功能标签读取。

## 尺寸与分组

支持边缘、角落和右下角手柄拖动，最小尺寸为 640 × 240。设置菜单提供同等可用的尺寸操作：紧凑 640 × 240、标准 900 × 240、宽大 1200 × 240，以及恢复默认大小。预设和拖动结果都保存到本机；切换屏幕时限制在屏幕可用范围内。旧默认高度 288 或 352 只在本次布局升级时迁移为 240，其余自定义尺寸保持；升级使用独立标记，不受上一版的升级标记影响。

面板过渡使用单个可取消的动画控制器，以单调时钟推进位置和透明度。反向切换从当前状态开始，取消的过渡不执行完成回调。进入位移 8 pt、退出位移 6 pt；完成后恢复稳定位置，拖动开始时停止过渡，不将动画位置写成用户尺寸。

窄窗口保留搜索和必要工具按钮，分组标签横向滚动。设置中的“切换分组”子菜单列出全部分组，即使标签被裁切，也能从菜单进入。

## 预览与空状态

文字和链接预览显示完整内容，可滚动和选择；图片预览从本机历史副本读取，并保持比例；文件预览显示原始路径，不打开原文件。预览作为面板的子窗口，关闭面板、切换应用或删除对应记录时一并关闭。

没有历史、搜索无匹配、类型筛选无结果、分组为空和记录暂停时，分别显示中文说明和下一步操作。

## 验证范围

本地自检覆盖 640 × 240、640 × 272、640 × 288、800 × 336、1200 × 240、1200 × 288、1000 × 620 的工具栏和卡片布局，验证短长内容等高，面板调整高度与搜索筛选不会改变卡片尺寸。检查还覆盖边缘与手柄点击范围，实际拖动，尺寸菜单回调，常驻搜索、光标与空格输入，搜索后选择，分层 Esc，文字/文件/图片预览和关闭清理，以及分组菜单。圆角检查验证材质遮罩四角透明、中心不透明和可拉伸边距；动画检查验证连续反向切换、尺寸稳定、完成回调只执行一次、取消和减少动态效果。

正文按可用空间限行；链接标题与网址各一行，文件图标为 24 pt。被截断的内容可通过空格、右键或辅助功能操作预览。面板高度不超过 260 pt 时隐藏 162 pt 的欢迎引导卡片，使用帮助仍可从设置菜单查看。

原有检查覆盖复制、固定、容量、持久化、敏感标记、1/3/5/7 天保留期限、到期图片副本清理与原文件保留。界面预览只使用示例内容，人工检查浅色、深色、窄窗口与较高窗口布局。VoiceOver 完整操作与不同真实桌面背景下的所有文字对比度尚未进行专项测量。

Paste 参考交互检查使用独立测试剪贴板，验证首次搜索回车不复制、结果回车复制正确内容、双向 Tab、搜索编辑与按钮焦点保留、空结果不退出、跨分组匹配及清除后恢复、类型筛选显示与清除、分组快捷键循环与筛选保留、来源应用名称。参考来源及实现范围见 [Paste 交互参考](PASTE-REFERENCE.md)。

精简界面检查验证卡片没有常驻按钮，右键及辅助功能操作仍能预览与固定，卡片按压仍能复制，设置按钮保留原生焦点。正常底部不显示常驻提示，搜索时错误通知与暂停状态仍可见。显示选项刷新检查通过 NSWorkspace 通知确认现有面板、卡片更新且尺寸不变；未自动更改用户的系统辅助功能设置。
